# 时间记录仪 1.0.0

本地、隐私优先的 Windows 文件变化记录器。它只在本机记录你关心的目录里发生了什么文件变化，**不上传任何数据**。

---

## 一、运行

1. 把整个压缩包**解压到一个目录**，例如 `D:\时间记录仪`。
   ⚠️ 请不要只把 `WindowsChangeJournal.exe` 单独拖出来 —— 同目录下的 dll 和运行时文件是必需的。
2. 双击 `WindowsChangeJournal.exe` 即可启动。
3. 这是**自包含版本，不需要安装 .NET 运行时**，也不写注册表、不需要安装过程。
4. 程序启动后常驻**系统托盘**（屏幕右下角，可能收在 `^` 里），双击托盘图标打开主界面。

想删除程序：托盘菜单 → 退出，然后把解压出来的整个目录删掉即可。

---

## 二、第一次使用

- **默认开启「全局记录」**：实时监听本机所有可用固定磁盘。
- 想只盯几个目录：打开「设置」→ 关闭全局记录 → 添加自定义目录（提供桌面、文档、下载等快捷候选）。
- 全局模式只建立实时监听，**不做启动预扫**，所以启动很快，也不会因为扫整盘而卡顿。
- 托盘菜单可以：打开主界面、暂停记录、15 分钟暂停、1 小时暂停、恢复、退出。

---

## 三、界面速览

| 区域 | 作用 |
|---|---|
| 左侧时间线 | 按时间倒序列出事件：创建、修改、重命名、移除、移动 |
| 筛选条 | 文件名 / 旧路径 / 新路径 / 事件类型 / 来源 / 目录 / 时间范围，可任意组合；事件类型和来源是多选勾选菜单 |
| 右侧详情 | 完整路径、时间、大小、来源分类、文件身份证据强度（已确认 / 可能），以及「关联程序（按路径推定）」——可以直接开启或停止记录该程序目录的新变化 |
| 文件历史 | 查看某个文件的历史变化，并验证它当前是否还在原位置 |
| 完整性 / 健康面板 | 记录缺口、数据库统计、运行状态 |
| 导出 | 把当前筛选结果导出为 CSV 或 JSON（CSV 已做公式注入防护） |

## 四、关于「来源」的含义（重要）

事件里的「来源」是**根据文件路径和当时的前台程序推定**的，**不是抓到了真正的写入进程**：

- 「人为操作」——仅在检测到资源管理器等文件管理器位于前台时使用。
- 能从程序目录识别出软件时，直接显示软件名，例如「Codex（推定）」。
- 其余无法关联到具体程序的事件，归为「软件操作（推定）」。
- **Windows 系统后台文件变化**默认不入库，可在设置里单独开启。
- **Microsoft Defender 隔离 / 保护历史相关变化**有独立开关，默认关闭。
- 来源开关只影响**之后新产生**的事件，不会删除已有历史。

---

## 五、隐私

- 不记录键盘输入、剪贴板正文、屏幕截图、麦克风、聊天内容、网页正文或**文件正文**。
- 程序**不含任何网络上传功能**，所有数据只写在本机。
- 私密目录可以排除，排除在**写入数据库之前**生效。
- 前台应用或正在运行的应用可触发全局暂停，离开后等 3 秒稳定时间再恢复。

## 六、数据存在哪

```text
%LOCALAPPDATA%\WindowsChangeJournal\config.json
%LOCALAPPDATA%\WindowsChangeJournal\config.json.bak
%LOCALAPPDATA%\WindowsChangeJournal\events.db
```

（在文件资源管理器地址栏粘贴 `%LOCALAPPDATA%\WindowsChangeJournal` 即可打开。）

- **想换位置**：设置环境变量 `WINDOWS_CHANGE_JOURNAL_DATA_DIR` 指向目标目录，再启动程序。
- **卸载或删除程序不会自动删除历史数据**，需要自己手动删掉上面这个目录。
- 默认保留 **30 天**、占用上限 **512 MB**，都可以在设置里调整，超限自动维护。

---

## 七、已知边界（这些是设计取舍，不是 bug）

- 目录通知能证明「路径发生了变化」，但通常**不能证明是谁改的**，也无法区分「删除」和「移出未监控范围」。
- 同一监控目录内的重命名由系统直接报告；**跨监控目录的移动**优先用稳定文件身份关联，没有身份时只把短时间内名称和大小一致的记为候选 —— 可能漏判或误判。
- 程序退出、暂停或系统通知缓冲区溢出期间发生的变化**不会补录**，程序会把这些区间明确记为「记录缺口」，不假装完整。
- 暂停期间不补录；修改事件按 2 秒窗口合并，避免连续保存刷屏。
- **文件历史不是备份**：不保存文件内容，也不能还原旧版本，更不会自动移动文件。
- 不能把符号链接、目录联接或挂载点直接设为监控根目录，请选择它实际指向的目录。

## 八、系统要求

- Windows 11 x64（Windows 10 可运行，但未作为正式验收范围）。
- 本自包含版本无需安装 .NET。

---

## 九、出问题怎么办

1. 先看界面里的「完整性 / 健康」面板，里面的记录缺口和统计通常能说明问题。
2. 托盘图标没了 / 程序像没在跑：检查托盘折叠区 `^`，或在任务管理器里确认 `WindowsChangeJournal.exe` 是否还在。
3. 数据库疑似损坏：先退出程序，把 `events.db` 改名备份，再启动程序会重建空库（历史会丢，所以务必先备份）。
4. 记录不到某个目录：确认该目录没有被加进「排除目录」，且没有处在暂停状态。

---

本项目是本地工具，所有处理都在你自己的电脑上完成。
